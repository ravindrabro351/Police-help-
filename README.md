## 🚀 What is MUKU EXPLOITS?

**MUKU EXPLOITS ** is a next-generation IMEI intelligence platform built for the modern web. Whether you're buying a used phone, verifying device authenticity, or just curious about any mobile device — this tool gives you instant, actionable information.

Built with **zero dependencies**, **zero backend**, and **zero tracking** — everything runs locally in your browser for maximum privacy.

---

## ✨ Features

- ⚡ **Real-Time IMEI Validation** — Live Luhn checksum verification as you type
- 🔍 **Smart TAC Decoding** — Extract Type Allocation Code & Reporting Body
- 📱 **10,000+ Device Database** — Covers Apple, Samsung, Xiaomi, OnePlus, Google, Vivo, Oppo, Realme & more
- 🖼️ **Auto Device Images** — Real product images with smart fallback
- 🌐 **Multi-Language Support** — English & Hindi
- 📊 **Bulk IMEI Checker** — CSV upload & batch processing
- 📸 **Camera IMEI Scanner** — Scan barcodes/QR with device camera (BarcodeDetector API)
- 🔗 **QR Code Generator** — Generate QR for any IMEI
- 📤 **Share as Image** — Export results as shareable PNG
- 🌙 **Dark Mode Ready** — Modern government-portal style UI
- 📱 **Fully Responsive** — Works on mobile, tablet, desktop
- 🔒 **100% Private** — No data ever leaves your browser
